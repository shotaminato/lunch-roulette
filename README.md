# 🍱 ランチルーレット

今日のランチをルーレットで決める、単一ファイルの Web アプリです。依存パッケージはなく、ブラウザだけで動きます。

## 使い方

1. 「まわす！」を押すとルーレットが回り、今日のランチが決まります。
2. 候補は画面下部から追加・削除できます。
3. 候補はブラウザの `localStorage` に保存されるので、同じ端末・同じブラウザなら次回も残ります。

初期候補は ラーメン / カレー / 定食 / パスタ / 寿司 / ハンバーガー です。

## GitHub Pages

リポジトリの `main` ブランチのルートを GitHub Pages の公開元にすると、次の URL で開けます。

https://shotaminato.github.io/lunch-roulette/

スマホのブラウザからこの URL を開いて使えます。
